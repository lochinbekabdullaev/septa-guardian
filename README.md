# septa-guardian

This project creates a route for the user based on the starting location, destination, and departure time entered, with additional accessibility features for disabled people.

## Features

- Real-time updates based on SEPTA service alerts
- Accessibility features such as specific route planning for wheelchair users and text-to-speech for visually impaired users
- AI-Powered guidance combining verified route data with live SEPTA information
- Adjusts route to avoid specified stations based on user preferences
